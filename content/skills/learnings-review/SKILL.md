# Learnings Review

Resolve the active harness install root from this skill's known `skills/learnings-review/`
location and read `hooks/logs/learning_log.log`, or use an explicit user-provided log.
Respect custom homes. Missing/disabled logging is a no-data result, not an error.
Do not reconstruct logs from credentials, private histories or unrelated raw output.

Inspect only structured redacted diagnostics. Group causes and verify repeated failures against
current project commands. Prefer a small project AGENTS.md rule for a lasting fact; report
one-offs. Do not copy secrets, token-bearing commands or build-output bodies.
When the redacted records provide them, compare diagnostic signatures and distinct session
counts so repeated retries in one session are not mistaken for a recurring cross-project rule.

Review alone is read-only. Explicit promotion authorizes the scoped instruction update without
per-cluster consent; preserve existing instructions. Live global homes require separate authority.
Never truncate/delete logs automatically. Report sample limits and evidence for promoted lessons.
